# CPI-U alt measures — validação da série INDEX

**Last date**: 2026-09. Fonte: `data/cpi_cpius_alt_measures.csv`. Index rebase: Jan/2000=100 (custom = primeira obs=100 pq começa 2001-01).

Esse dashboard foi gerado pra **conferir se o index está mantendo conta** depois do sync 2026-10-28 (SQL CPI alt agora só sobe level, não mais rate).

**Metodologia do index**: `idx[t] = idx[t-1] * (1 + mom[t])` com `mom = (1+ann_1mo/100)^(1/12)−1`. Rebase final pra Jan/2000=100 por measure. Atlanta não publica index level nativo (col 1 do xlsx é MoM decimal), então a reconstrução do index é universal via chain-from-ann_1mo.

**Checks**:
1. **Chain fidelity** (tabela abaixo): max|diff| entre YoY/MoM derivado do index vs valor publicado — tem que ser `~0` pra toda measure com overlap.
2. **Anchors long-run**: idx em datas de referência (1983, 2000, 2010, 2020, last) — verificar monotonia implícita e magnitude plausível.
3. **Side-by-side último ano**: YoY derivado vs publicado em cada mês dos últimos 12m; coluna de diff tem que ser `0.00`-ish.
